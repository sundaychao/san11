## 容器与组件

- 桌面：64px 顶栏、全幅地图、右侧 320px 城市面板、左下日志、右下小地图。
- 手机：56px 顶栏、全屏地图、最高 58dvh 的底部城市面板。
- 允许的工具容器：顶栏、城市面板、日志、小地图、模态对话框。
- 禁止卡片套卡片、营销式英雄区、装饰渐变、发光球和大圆角胶囊。
- 重复控件使用统一按钮、数值行和命令网格变体。

## 图标

- 使用 Lucide 线性图标，默认 18px、1.8px 描边。
- 保存：`Save`；进行：`SkipForward`；开发：`Landmark`；征兵：`Users`；训练：`Swords`；巡察：`ShieldCheck`；人才：`UserSearch`；调动：`Route`；关闭：`X`。
- 图标按钮必须有 `title` 与可访问名称。

- 城市标记包含势力色、城名、所属势力和兵力。

- 禁用命令显示明确原因；提交成功后更新城市数值、日志和存档。
- 地图拖动缩放与小地图视口同步。
- 第 24 月结算显示排名，但允许查看最终地图与重新开局。
