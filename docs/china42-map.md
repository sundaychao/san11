# 华夏 42 城大地图（200×200）

数据：`public/maps/china42.json`（编辑器导入格式，schemaVersion 1）
预览：`public/maps/china42.svg`
生成器：`src/game/map-editor/generators/china42.ts`（纯函数，种子固定可复现）
重新生成：`npm run map:china`

## 设计说明

- **地理骨架**参照真实中国：东部海岸线（渤海湾、山东半岛、长江口）、黄河「几」字形、长江、汉水、淮河、湘江、赣江、珠江、辽河；青藏高原东缘、阴山、燕山、太行山、吕梁山、秦岭、大巴山、巫山、陇山、大别山、南岭、武夷山等山系。
- **42 座城市**按三国志 11 城市名单与相对方位落位：河北（襄平/北平/蓟/南皮/平原/邺/晋阳/上党）、中原（濮阳/陈留/谯/洛阳/小沛/北海/汝南/许昌）、西北（长安/安定/天水/武威/汉中）、巴蜀（梓潼/成都/江州/永安/建宁/云南）、荆楚（宛/新野/襄阳/江陵/长沙/武陵/零陵/桂阳）、扬越（寿春/庐江/柴桑/建业/吴/会稽）、徐淮（下邳）。
- **道路网**按历史商道连接相邻城市，由 Dijkstra 自动寻路生成：穿山处开出 1 格宽的隘口走廊（如函谷、剑阁式通道），跨河处自动设为渡口。
- **渡口**：官渡、白马、孟津、蒲坂、夏口、荆州、京口、柴桑、淮上、湘江、辽西等 11 处名渡，配合「岸边停靠」规则形成江河防御玩法。
- 地形消耗与移动规则沿用 `docs/GAME_RULES.md` §7/§9。

## 使用方式

1. 开始任意单机对局后打开「地图编辑器」。
2. 选择导入 JSON，选取 `public/maps/china42.json`。
3. 地图与城市坐标立即应用到当前对局（当前剧本的城市名册不变，仅地形与坐标替换；独立的 42 城剧本为后续扩展）。

注意：200×200 共 40,000 格，浏览器一次性渲染全部格子可能较慢，属于已知性能边界。
