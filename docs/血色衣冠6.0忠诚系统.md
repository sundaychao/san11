## ０. 版本脉络

| 版本 | 配套 SIRE | 忠诚 / 登用系统变化 |
|---|---|---|
| 6.0 早期 | 2.08k | 修复「部分特殊武将作为君主时忠诚度绝对不下降」的 BUG |
| sp9 | **2.09d** | **重做忠诚度与登用意愿系统**：取消禁仕期改仕龄、引入忠诚度基准值、新增定期下降规则、重写登用意愿公式 |
| sp10 | **2.09e** | 参数重订（基准登用 72/68/64）、相性差引入「登用武将」过渡、登庸界面四档颜色标注意愿、论客附加强化、君主魅力对下降的系数 50%→40% |

2.09 引入的两条底层改动（后续所有公式的前提）：

- **取消「禁仕期」，改为「武将仕龄」** —— 武将每次改换东家，仕龄从 1 重新开始计算。被俘期间仍然累计仕龄（sp10 明确）。
- **武将自主变更势力的计数** 与仕龄一起可在修改器中编辑（与禁仕君主 / 禁仕期互斥）。

## 一、忠诚度基准值

**作用**：武将忠诚度能被「褒奖」拉到多高，就取决于这个基准值 —— 不再是原版的固定 100 上限。

```
忠诚度基准值 = 100
             − 相性差(与君主) × A%
             + 仕龄(年) × B%
             + 官阶 × C
             + 与君主关系
             + 同势力仲介 / 结婚 / 结义
```

| 项 | 取值 |
|---|---|
| 相性差(与君主) | 按 A% 折算，相性差越大基准越低 |
| 仕龄(年) | 每满一年按 B% 加成 |
| 官阶 | 无官职 0，最高官职视为 10 阶；C=2，即满官阶时 **+20** |
| 与君主关系 | 亲爱 **+10** / 厌恶 **−10** / 一族 **+5** / 父母子女 **+10** / 结婚 **+10** / 结义（每人）**+5** |

**要点**：相性差是最大负项。这解释了 sp9 时期「每个与君主相性差大的武将都很难被登用、君主麾下相性必然高度集中」的现象。

## 二、定期忠诚下降

每季换季（以及每月符节台判定）触发。

```
下降概率 = (基准值 − 君主属性) × 比例A%
         + (功绩 − 官阶 × 每级官阶所需功绩) × 比例B%

下降数值 = 浮动值(1~C) + 2 − 义理
```

- **君主魅力影响**：sp9 系数 **50%**，sp10 下调为 **40%**（2.7）。
- **君主魅力低 = 致命**，这是原版没有的判定项。
- **功绩相对官职过高**会额外拉高下降概率（新引入，防止高功绩低官职的武将不服）。
- **野心对下降数值的影响**：义理 / 野心取值均为 **0~4**
  - `0 → 除 4`、`1 → 除 2`、`2 → 不变`、`3 → 乘 2`、`4 → 乘 4`
- **符节台**：建有符节台时，该城市全部武将（含己方与俘虏）每月附加减忠。

### 判定分支

| 条件 | 结果 |
|---|---|
| 亲爱君主 | **必不下降** |
| 相性差小于 X 且不是俘虏 | 忠诚度不下降 |
| 厌恶君主 | **必定下降** |
| 高野心 + 低义理 | **必定下降** |
| 据点有「仁政」 | 走独立的必不下降分支 |

### 抑制手段

- **掌握人心** 科技：下降概率变为原来的 33%（原版数据）。
- **克己复礼**（文教类六级科技）：忠诚下降概率 **−50%**。
- 赵匡胤特技 **仁政**：武将忠诚永不下降。
- 注意：**出征在外的将领吃不到「褒奖」**，长期在外有被连人带部队拐走的风险。

## 三、登用接受意愿

> 「登用接受意愿 > 0 表示有接受登用的可能，通常该值在 20 以上便很容易成功。」

```
登用接受意愿 = 基准值
             + 浮动值(0 ~ A−1)
             − 相性差(与登用君主) × B%
             − 忠诚度(下限 60) × C%
             + 登用武将属性(魅力) × D%
             − 现任君主关系 × E%
             + 登用君主关系 × F%
             + 登用武将关系 × G%
             + H(是俘虏)
             − I(仕官第一年)
             − 义理 × J(有归属势力)
             + 野心 × K(无归属势力)
```

### 参数表（sp9 默认值）

| 符号 | 含义 | 默认值 | 换算 |
|---|---|---|---|
| 基准值 | 初始接受登用意愿 | **60**（sp10 重订为 **72 / 68 / 64**） | — |
| 浮动值 | 伪随机 | **6** | 取 0 ~ 5 |
| B | 相性差（与登用君主） | **50%** | 每 2 点相性差 −1 意愿 |
| C | 忠诚度 | **100%** | 1 点忠诚 −1 意愿；**低于 60 按 60 算**，在野武将忠诚默认 60 |
| D | 登用武将魅力 | **20%** | 每 5 点魅力 +1 意愿，100 魅力 = +20 |
| E | 现任君主关系 | **−40%** | — |
| F | 登用君主关系 | **+40%** | — |
| G | 登用武将关系 | **+20%** | — |
| H | 是俘虏 | **+10**（sp10 截图显示为 0，待官方手册确认） | 无论有无归属势力 |
| I | 仕官第一年 | **−20** | 查仕龄是否为 1 |
| J | 义理（有归属势力） | **每点 −2** | 0~4，最多 **−8** |
| K | 野心（无归属势力） | **每点 +2** | 0~4，最多 **+8** |

> 浮动值是依据「登用武将 id、被登用武将 id、当前旬 number」生成的**伪随机数，SL 不会改变**。

### 人际关系值（三种关系共用同一套算法）

| 关系类型 | 关系值 |
|---|---|
| 亲爱 | **+10** |
| 厌恶 | **−60** |
| 一族 | **+5** |
| 结义 / 结婚 | **+10** |
| 父母 / 子女 | **+10** |
| 同乡 | **+5** |
| 仲介 | **+10** |

换算示例（作者原文）：

- 被登用武将与现任君主关系分为 20（父母 + 一族 + 同乡），现任君主系数 −40% → **−8**
- 被登用武将与登用君主关系分为 10（亲爱），登用君主系数 +40% → **+4**
- 被登用武将与登用武将关系分为 5（同乡），登用武将系数 +20% → **+1**

### 常见疑问

**「60 点忠诚为什么登不到？」** —— 因为「出仕第一年 −20」这一项。仕龄为 1 的武将，实际意愿被硬扣 20 点。

### 硬性判定（不走公式）

| 条件 | 结果 |
|---|---|
| 目标是君主 | 走 N 线（直接拒绝） |
| 忠诚度高于 **96** | **必定拒绝** |
| 厌恶登用君主 | **必定拒绝** |
| 亲爱登用君主，且目标在野或俘虏 | **必定同意** |
| 厌恶 / 亲爱登用武将 | 可配置是否参与判定（不打勾则不判断） |

## 四、sp10（2.09e）相对 sp9 的关键调整

1. **基准登用值重订**：60 → **72 / 68 / 64**（三档难度），整体**降低登用难度**。
2. **相性差引入「登用武将」过渡**（2.5.1）—— 这是本次最重要的机制改动：
   - 原规则：相性差只看「被登用武将 ↔ 登用君主」。
   - 新规则：若被登用武将与**登用君主**相性差为 60，而**登用武将**与被登用武将相性差为 0，则修正后的相性差为 **30**。
   - 实战意义：**可以形成「相性群团块」**。君主相性 20，一旦登用到相性 100 的高魅力武将，就能依托这名武将逐步吸收相性 100 左右的武将集团 —— 「只要撕开一个口子，其他口子也同样好撕」。
3. **登庸界面四档颜色标注意愿**：深绿 = 意愿高 / 浅绿 = 意愿中 / 浅黄 = 意愿小 / 白 = 无意愿。此前只有忠诚值可参考。
4. **论客**：附加效果 —— 增加其它势力武将接受登用意愿 **+5**（与「清谈」互补，清谈专攻在野、论客专攻势力武将）。
5. **君主魅力对忠诚下降的系数**：50% → **40%**。
6. **被俘时仍然累计仕龄**。
7. **亲善费用**：2000 → **1200**（三档 800 / 1000 / 1200）。
8. **行动力恢复改由君主政治决定**，而非魅力。

## 五、与新忠诚系统绑定的新增特技（2.09 引入）

| 编号 | 特技名 | 效果 | 数值 |

| 394 | 不愿叛变 ★ | 作为**仕官**武将时，接受登用意愿降低 | −20 |
| 395 | 不愿出仕 ★ | 作为**在野**武将时，接受登用意愿降低 | −20 |
| 396 | 善于劝说叛变 ★ | **登用仕官武将**时，提升对方接受意愿 | +10 |
| 397 | 善于劝说出仕 ★ | **登用在野武将**时，提升对方接受意愿 | +10 |
| 398 | 仕龄加统 ★ | 按仕官年数获得附加统率 | 仕龄 × 20%，上限 4 |
| 399 | 仕龄加武 ★ | 按仕官年数获得附加武力 | 仕龄 × 20%，上限 4 |

## 六、对玩法的影响

**玩家侧**

- 褒赏不再是「季度开始时点几下」就完事 —— 相性差大、官阶低、仕龄短的武将会持续掉忠诚。
- 可用武将数量实际下降，魏延、孟达这类义理低野心高的武将「一言不合就跑路」。
- 对策优先级：**仁政** > 结义 / 结婚 > 掌握人心 / 克己复礼 > 提高官阶 > 避免主力长期在外。

**登用侧**

- 挖人从「是个人就能干」变成需要同时考虑：相性、特技、武将关系、仕龄、俘虏状态。
- sp10 后**相性群团块**是核心思路：先用高魅力武将打下相性据点，再靠它滚雪球。
- 颜色标注让「谁登得动」一眼可见，不必逐个试。

**AI 侧**

- 注意 2.10 修复了「委任军团随意移动武将」的 BUG；2.08h 修复了「AI 会无限登用事件在野武将」和「AI 不需论客及玩家同意强制进入舌战」的 BUG。
