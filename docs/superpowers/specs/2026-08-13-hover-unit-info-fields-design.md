# 部队悬停情报字段精简设计

## 目标

精简地图上鼠标悬停部队时显示的情报面板，移除“士兵”和“兵科”两项。

## 范围

- 悬停情报保留主将、副将、统率、武力、智力、适性、资金、兵粮和士气。
- 悬停情报不再显示士兵数量及兵科名称。
- 部队详细情报窗口、地图部队标记、出征界面及战斗计算不受影响。

## 实现

- 从 `UnitInfoPanel` 的资源信息列表中删除“士兵”和“兵科”两行。
- 删除该组件中因此不再使用的兵科标签映射及辅助函数。
- 更新悬停情报测试，明确断言面板中不存在“士兵”和“兵科”，同时确认保留字段仍显示。

## 验证

- 先运行新增测试并确认在实现前失败。
- 完成最小实现后运行相关组件测试。
- 运行完整测试与生产构建，确认没有影响详细情报和其他战斗界面。
