# 整格对齐水墨地图生成设计

## 目标

根据以下导出文件生成一张 `1680x960` 的写实古代中国水墨战术地图背景：

- `terrain-control.svg`
- `mask-water.svg`
- `mask-mountain.svg`
- `mask-forest.svg`
- `mask-road.svg`
- `mask-city.svg`

地图服务于现有 70x40 错列方格战场。生成图片只作为可替换背景，地形规则仍以地图编辑器导出的网格数据为准。

## 视觉方向

整体采用写实古代水墨沙盘风格：淡宣纸底色、青灰水面、墨色山岭、深绿森林、土黄道路和低饱和城池。图片中不绘制网格线，不添加地名、文字、旗帜、部队、人口信息或其他界面元素。

## 严格对齐约束

- 输出尺寸固定为 `1680x960`。
- 使用 70x40 网格和 24 像素单元格。
- 偶数列向上偏移半格，即 12 像素。
- 水域只能出现在 `mask-water.svg` 的完整白色方格中。
- 道路只能出现在 `mask-road.svg` 的完整白色方格中，并铺满对应方格。
- 单个水域格不得同时出现平原、河岸或其他地形。
- 单个道路格不得同时出现普通平原地表。
- 山地、森林和城池同样不得侵入遮罩以外的方格。
- 地形交界处使用遮罩硬裁切，不使用跨格羽化、模糊或渐变。

## 生成方案

采用“水墨材质生成 + 遮罩严格合成”的混合方案。

先生成或制作平原、水域、山地、森林、道路和城池的写实水墨材质，再按照导出的黑白遮罩合成。AI 只负责材质和局部地貌观感，不负责决定地形位置。最终像素归属由遮罩确定，从而兼顾写实水墨效果和方格边界准确性。

## 图层结构

从下到上的合成顺序为：

1. 宣纸和平原底层。
2. 山地层。
3. 森林层。
4. 水域层。
5. 道路层。
6. 城池层。
7. 统一的淡墨纸纹和色彩校正层。

最上层纸纹只能影响颜色和明暗，不得改变任何地形的空间边界。

## 数据流

1. 读取用户提供的六个 SVG。
2. 校验画布尺寸、网格尺寸、单元格尺寸和遮罩类型。
3. 将控制图和遮罩渲染为同尺寸参考图。
4. 生成水墨地形材质。
5. 使用二值遮罩逐层合成。
6. 输出 PNG 预览到 `exports/`。
7. 检查水域、道路、山地、森林和城池是否完全落在对应遮罩内。
8. 将成图作为地图编辑器的校准底图，后续规则修正仍通过网格数据完成。

## 输出

主要输出：

- `exports/ink-wash-map-cell-aligned.png`

可保留用于复核的合成源文件或中间预览，但不自动提交生成资源。

## 错误处理

- 任一输入文件缺失时停止生成并报告缺失文件。
- 输入画布不是 `1680x960` 时停止生成。
- 网格不是 70x40 或单元格不是 24 像素时停止生成。
- 遮罩不是黑底白色目标区域时停止生成或先规范化为二值遮罩。
- 生成材质无法满足写实要求时只重新生成材质，不修改网格和遮罩。

## 验证

- 比较最终水域像素与水域遮罩，确认不存在遮罩外水面。
- 比较最终道路像素与道路遮罩，确认不存在遮罩外道路。
- 抽查地形交界单元格，确认每格只有其指定地形。
- 确认最终图片没有可见网格线、文字、旗帜、单位或界面元素。
- 视觉检查山地、森林、水域、道路和城池的写实水墨一致性。
- 如涉及项目代码变更，运行 `npm.cmd test` 和 `npm.cmd run build`。
